# LogIt

A WebStorm / IntelliJ Platform plugin to quickly insert and remove JavaScript
`console.log()` statements. Built with Kotlin and the
[IntelliJ Platform Gradle Plugin](https://github.com/JetBrains/intellij-platform-gradle-plugin)
2.x.

- **Plugin ID:** `org.lso.logit`
- **Target IDE:** WebStorm 2026.2.1 (IntelliJ Platform build `262`)
- **Version:** 2026.2

## Features

- **Insert log** — smart `console.log()` insertion
  - macOS: `⌥ + L` · Windows/Linux: `Alt + L`
- **Remove logs** — delete `console.log()` statements generated by LogIt
  - macOS: `⌥ + ⇧ + L` · Windows/Linux: `Alt + Shift + L`

## Requirements

- **JDK 19 or newer** (JBR 21 recommended — bundled with WebStorm 2026.2)
- Internet access on first build (Gradle downloads the IntelliJ Platform and
  dependencies)

## Build

The project includes the Gradle Wrapper, so you do **not** need Gradle
installed. From the project root:

```bash
# Full build (compiles, tests, and packages the distributable)
./gradlew buildPlugin
```

On Windows use `gradlew.bat` instead of `./gradlew`.

### Build output

| Artifact | Path | Purpose |
| --- | --- | --- |
| **Distributable (zip)** | `build/distributions/logit.zip` | Installable plugin package — **this is what you distribute** |
| Raw JAR | `build/libs/logit-2026.2.jar` | The plugin's compiled archive |

> **Note on "JAR" vs "ZIP":** IntelliJ plugins are distributed as a `.zip`
> archive (containing the plugin JAR(s) and metadata), not a bare `.jar`. Always
> use `build/distributions/logit.zip` for installation and Marketplace upload.
> The `.jar` in `build/libs/` is the unpacked archive content for reference only.

To build without tests:

```bash
./gradlew buildPlugin -x test
```

To clean previous artifacts first:

```bash
./gradlew clean buildPlugin
```

## Run in a development IDE

Launch a sandboxed WebStorm instance with the plugin installed, so you can test
changes without touching your real IDE:

```bash
./gradlew runIde
```

## Verify compatibility

Check the plugin against the target IDE before releasing:

```bash
./gradlew verifyPlugin
```

Reports are written to `build/reports/pluginVerifier/`.

## Install the built plugin

1. Build it: `./gradlew buildPlugin`
2. In WebStorm/IntelliJ: **Settings/Preferences → Plugins → ⚙ → Install Plugin
   from Disk…**
3. Select `build/distributions/logit.zip`
4. Restart the IDE

## Distribute

### Manual sharing

Share `build/distributions/logit.zip` — anyone can install it via
"Install Plugin from Disk…" as described above.

### Publish to JetBrains Marketplace

The `publishPlugin` task uploads the zip to the Marketplace. Provide your
publishing token via an environment variable (the build reads
`ORG_GRADLE_PROJECT_intellijPublishToken`):

```bash
export ORG_GRADLE_PROJECT_intellijPublishToken=<your-marketplace-token>
./gradlew publishPlugin
```

Get a token from your [JetBrains Marketplace account](https://plugins.jetbrains.com/).

## Useful Gradle tasks

| Task | Description |
| --- | --- |
| `buildPlugin` | Build the distributable zip |
| `runIde` | Run the plugin in a sandboxed IDE |
| `verifyPlugin` | Verify compatibility with the target IDE |
| `publishPlugin` | Publish the zip to JetBrains Marketplace |
| `test` | Run unit tests |
| `clean` | Remove `build/` outputs |
